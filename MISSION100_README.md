# Mission 100 P0: persist stopped at `unexpected file: alignment.json`

## Root cause (code-confirmed)
- `tools/mission79-build-ward-2025.cjs` always writes `<out>/alignment.json` (road-vs-building orientation scan, numbers only:
  roadPolygons, buildingPoints, per-transform hits, bestTransform, orientationOk, margin; or `{skipped}`). `mission79-run.mjs` passes `--tran`.
- `inspectOut()` in `tools/mission87-persist.mjs` allowed only tileset/source/build-report + glb + ids/attrs/tiles/lod dirs, so it threw.
- Conversion, strict check and manifest re-verify were correct; the generator and the allow-list were simply inconsistent.
- No secrets / personal data / extra licence: derived from the already-public PLATEAU 2025 tran + building geometry.

## Fix
- `alignment.json` is an exact-name, optional, schema-validated file (size <= 64KB, known keys only, known transform names, numeric fields).
  Malformed / extra-key content is rejected. No wildcard. `crosswalk.*`, `legacy-only-ids.json` (only with `--legacy`, never used by the workflow) stay rejected.
- Tests: `tests/mission100-alignment.test.cjs` (also checks every top-level file the generator writes is covered).
